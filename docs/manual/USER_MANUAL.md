## 一、 软件概述与准备工作

**LanShare** 是一套专为局域网内部高速、稳定传输百兆/吉字节（GB/TB 级）大文件及多级复杂文件夹而设计的桌面应用。

### 🌟 核心能力
1. **整文件夹递归互传**：无论下载还是推送，100% 保持原始多级目录树结构，无需手动压缩打包。
2. **工业级断点续传**：基于 HTTP Range 分块寻道与 10 次自动防抖重试，应对网络闪断无缝续传。
3. **毫秒级 UDP 自发现**：客户端开机自动探测在线服务端，免去手动查找与输入 IP 的繁琐步骤。
4. **Windows 快捷方式穿透**：支持直接点选 `.lnk` 快捷方式，自动毫秒级穿透解析至真实目标文件夹。
5. **动态准入与免密双模式**：支持 4 位动态验证码与服务端人工审核，亦支持一键开启局域网免密直连。

## 二、 程序分发包与文件说明

解压发布的绿色分发压缩包后，您将获得两个核心独立程序包：

```text
LanShare_Release/
├── 📁 client_app.dist/                 # 【客户端程序包】（用于普通局域网电脑，接收或推送文件）
│   ├── LanShareClient.exe             # 纯净 GUI 运行程序（无命令行黑框，日常推荐使用）
│   └── LanShareClient_debug.exe       # 调试版运行程序（带黑框控制台日志，用于排查网络问题）
│
└── 📁 server_app.dist/                 # 【服务端程序包】（用于存放共享文件的主机/服务器）
    ├── LanShareServer.exe             # 纯净 GUI 运行程序（无命令行黑框，日常推荐使用）
    └── LanShareServer_debug.exe       # 调试版运行程序（带黑框控制台日志，用于排查网络问题）
```

> ⚠️ **权限说明**：
> * **服务端（Server）**：需要管理员权限运行（程序启动时会自动弹出 Windows UAC 提示，点击“是”即可，用于自动在 Windows 防火墙中放行服务端口）。
> * **客户端（Client）**：纯普通用户权限运行，**绝不弹出任何提权提示**，可直接在受限办公电脑上使用。

## 三、 服务端（LanShareServer）使用指南

服务端用于将本地磁盘中的某个文件夹共享到局域网中，并接收客户端推送上传的文件。

### 1. 启动与界面总览
* 双击运行 `LanShareServer.exe`，在弹出的 UAC 授权窗口中点击 **“是”**。
* 服务端主界面包含：
  - **顶部操作栏**：包含「🔐 验证码」安全管理按钮。
  - **网络与状态卡片**：展示当前服务状态、监听端口（默认 8080）以及本机所有可用网卡 IP（标注 WiFi / 有线 / 网线直连）。
  - **共享目录卡片**：展示当前对外共享的本地物理文件夹路径。
  - **实时日志区域**：滚动记录连接审计、验证码校验、设备接入与文件传输事件。

### 2. 设置共享文件夹
1. 点击界面中的 **「📂 选择目录」** 按钮。
2. 在弹出的系统文件对话框中，选择您希望对外共享的本地文件夹（**亦可直接点选 Windows `.lnk` 快捷方式**，系统将自动穿透解析至真实物理路径）。
3. 选定后，界面将显示当前生效的绝对路径，并自动保存配置。

### 3. 启动文件传输服务
1. 点击右侧绿色的 **「🚀 启动服务」** 按钮。
2. 启动后：
   - 状态指示灯变为绿色「🟢 服务运行中」。
   - 程序已全自动放行 Windows 防火墙 TCP 服务端口（如 8080）与 UDP 8088 广播发现端口。
   - 局域网内的所有 LanShare 客户端即可发现并连接该服务端。

### 4. 权限验证与设备白名单管理
点击服务端顶部操作栏的 **「🔐 验证码」** 按钮，弹出安全管理面板：

* **查看与刷新动态码**：
  - 中间大号显示当前的 **4 位动态验证码**（例如 `A8K2`）。
  - 验证码每 120 秒自动轮换一次，底部进度条显示剩余倒计时，亦可随时点击「🔄 刷新」立即生成新码。
* **设备连接审批**：
  - 当客户端输入正确验证码发起连接时，服务端屏幕会**自动弹出设备授权请求**（显示申请者的计算机名与 IP 地址）。
  - 点击 **「✔ 允许并加入白名单」** 后，该设备即成功接入，后续无需再输验证码。
* **免密直连总开关**：
  - 面板顶部提供 **「启用客户端连接权限验证」** 开关。
  - 若在受信任的封闭局域网或内部测试环境中，可直接**关闭此开关**，所有局域网电脑即可免密直连浏览与传输。
* **白名单维护**：
  - 面板下方展示当前会话已授权的设备列表，支持单项移出（`✖`）或「清空全部白名单」。

## 四、 客户端（LanShareClient）使用指南

客户端用于从服务端拉取下载文件/整文件夹，或向服务端推送上传本地文件/整文件夹。

### 1. 启动与连接服务端
1. 双击运行 `LanShareClient.exe`（普通权限，零弹窗）。
2. **自动探测连接**：
   - 客户端启动后会自动向局域网广播探针，并在顶部下拉框中自动列出所有在线的服务端（标注机器名、IP、端口与延迟）。
   - 直接点击 **「🔗 连接」** 即可。
3. **手动连接**：
   - 若局域网禁用了广播，可在顶部输入框手动输入服务端的 `IP:端口`（例如 `192.168.1.100:8080`），点击「🔗 连接」。
4. **身份验证（如服务端开启了验证）**：
   - 界面将弹出 4 位验证码输入窗口。
   - 输入服务端显示的 4 位动态码并点击 **「提交验证」**。
   - 提交后界面显示“等待服务端管理员确认”，待服务端管理员点击允许后，弹窗自动关闭并加载文件列表。

### 2. 「📥 从服务端下载」标签页（Tab 1）
* **浏览多级目录**：
  - 列表清晰展示服务端共享的所有文件（📄）与子文件夹（📁）。
  - **进入子目录**：双击文件夹行，或点击右侧「📂 打开」。
  - **返回上级**：顶部提供「⬆ 返回上级」按钮与当前远端路径面包屑指示（如 `🌐 /docs/2026/`）。
* **下载单文件**：
  - 点击文件右侧的 **「📥 下载」**，文件将自动加入传输队列。
* **下载整文件夹（递归整包）**：
  - 点击文件夹右侧的 **「📥 下载」** 按钮。
  - 客户端将自动向服务端抓取该文件夹下所有深层子文件，并在本地下载目录下**自动递归创建对应层级的子文件夹**，下载后目录树与服务端 100% 一致。
* **更改下载保存目录**：
  - 顶部显示当前本地下载保存路径，点击「📂 更改」可更换保存位置（支持点选快捷方式）。

### 3. 「📤 向服务端推送」标签页（Tab 2）
* **浏览本地文件**：
  - 浏览本地待推送目录下的文件与文件夹。
  - 支持双击进入子文件夹与返回上级。
* **推送单文件**：
  - 点击文件右侧的 **「🚀 推送」**，文件立即推送到服务端共享目录。
* **推送整文件夹（递归整包）**：
  - 点击本地文件夹右侧的 **「🚀 推送」** 按钮。
  - 本地自动递归遍历所有深层子文件并加入队列，服务端自动按层级建立父文件夹并完整保存。

### 4. 传输监控与自适应 HUD 状态栏
传输启动后，主界面底部会自动滑出 HUD 状态栏：

* **单任务监控**：
  - 展示正在传输的文件名、瞬时速度（如 `85.4 MB/s`）、已用时长与动态预估剩余时间（ETA）。
  - 若正在传输文件夹，精准激活多文件进度胶囊：`📁 进度: 已传 3 / 共 12`。
* **多任务排队抽屉**：
  - 传输过程中，点击其他文件/文件夹的下载或推送均可**无缝加入排队列表**。
  - 点击状态栏中的 **「📋 排队 (N) ▾」** 按钮，状态栏平滑展开为独立抽屉，可查看待传任务清单，支持单项移出队列或「全部取消」。
* **断点续传机制**：
  - 传输大文件过程中若偶发断网，客户端底层会自动发起 10 次防抖重试，并在网络恢复后自动从断开的字节位置继续传输，无需重新从头开始。

## 五、 常见网络场景与使用技巧

### 场景 1：家庭 / 办公室常规 WiFi 与有线局域网
* **操作**：两台电脑连接同一路由器（WiFi 或网线插在同一路由/交换机上）。
* **效果**：客户端启动后 0.5 秒内自动搜索发现服务端，点击即可秒级连接。

### 场景 2：双机无路由器单根网线直连（极速 1000Mbps+）
* **操作**：无需交换机或路由器，直接用一根千兆网线将两台电脑的网口连接起来。
* **原理**：Windows 系统会自动为直连网卡分配 `169.254.x.x` 的私有链路本地 IP。
* **效果**：LanShare 原生适配了 `169.254.255.255` 网段广播，启动后直接自发现，传输速率可跑满千兆有线网卡硬件极限（~112 MB/s）。

### 场景 3：电脑开启了网络代理 / 抓包工具 / VPN
* **说明**：LanShare 传输核心内置了 `--noproxy "*"` 直连旁路机制，即使您电脑开启了全局科学上网代理或 Clash/v2ray 等 TUN 虚拟网卡，局域网传输流量也不会被错误代理，始终保持本地物理网卡高速直连。

## 六、 常见问题与故障排查 (FAQ)

### Q1: 客户端搜索不到服务端列表？
1. 检查服务端主界面的状态灯是否为绿色「🟢 服务运行中」。
2. 确认两台电脑是否在同一局域网内。
3. 若局域网路由器开启了“AP 隔离”限制了广播，请在客户端顶部输入框**直接手动输入服务端的 IP 地址与端口**（例如 `192.168.1.50:8080`），点击连接。
4. 查看服务端界面上列出的本机 IP，尝试使用其他网卡 IP 连接。

### Q2: 提示“连接被拒绝”或“连接超时”？
1. 确认服务端电脑上的第三方杀毒软件（如 360、火绒或 Windows Defender）是否拦截了服务端口。
2. 检查 Windows 网络属性，确保当前网卡网络类型为 **“专用网络 (Private Network)”**，而非公用网络。

### Q3: 为什么下载文件夹时本地没有生成？
* 请检查客户端设置的“本地下载保存目录”是否有足够的磁盘剩余空间以及写入权限。

### Q4: 传输大文件能中途暂停或取消吗？
* 可以。随时点击底部 HUD 状态栏中的「✖ 取消当前」或「全部取消」。取消后已传输的部分会被完整保留在本地磁盘，下次再次发起传输时会自动触发断点续传。
