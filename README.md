## 💡 它能为你做什么？

LanShare 专为解决办公网、家庭 WiFi、交换机有线网以及双机网线直连场景下的**大文件跨设备传输痛点**而设计：

* 📁 **整文件夹递归传输**：一键递归下载/推送整个文件夹，多级子目录结构 **100% 精准保持**，告别繁琐打包压缩。
* ⚡ **工业级断点续传**：基于 HTTP Range 协议与底层 `curl -C -` 10 次自动防抖重试，网络抖动或断线自动无缝恢复。
* 🔗 **Windows 快捷方式穿透**：直接选择 `.lnk` 快捷方式或软链接，纯二进制毫秒级自动解析至真实物理文件夹。
* 🔍 **毫秒级局域网自发现**：基于 UDP 广播自发现，开机自动探测在线服务端，免去繁琐查询与输入 IP 的烦恼（支持 `169.254.x.x` 直连网段）。
* 🔐 **安全准入与免密双模式**：提供 4 位动态验证码（120s 自动轮换）、服务端人工审批弹窗、`(Hostname, IP)` 复合白名单，并支持一键切换“局域网免密直连”模式。
* 📊 **智能队列与自适应 HUD 状态栏**：支持多文件混合排队与链式传输；传输时自动呈现瞬时速率、耗时、剩余时间（ETA）与 `已传 X / 共 Y` 多文件进度徽章。

## ⚡ 3 步极速使用指南

### 🖥️ 1. 服务端（提供共享文件的主机）
1. **启动程序**：双击运行 `LanShareServer.exe`（在弹出的 UAC 提示中点击“是”，程序将自动放行防火墙）。
2. **指定共享目录**：点击界面中的「📂 选择目录」，指定需要共享的文件夹（支持点选 Windows 快捷方式）。
3. **点击「🚀 启动服务」**：
   - 默认开启安全防护：点击顶部「🔐 验证码」可查看当前 4 位动态码。客户端提交连接申请后，点击弹窗中的「✔ 允许」即可建立连接。
   - 如需免密直连：在验证码弹窗中关闭「启用客户端连接权限验证」开关即可。

### 💻 2. 客户端（下载或推送文件的普通电脑）
1. **启动程序**：双击运行 `LanShareClient.exe`（纯普通用户权限，不弹出任何提权窗口）。
2. **连接服务端**：启动后将自动搜索局域网在线服务端并列出，点击「🔗 连接」（或在顶部手动输入服务端 IP:端口）。若服务端启用了验证，按提示输入服务端的 4 位动态码即可。
3. **文件传输**：
   - **📥 从服务端下载**：在下载标签页浏览服务端文件/子文件夹，双击进入目录，点击「📥 下载」即可单文件或整文件夹递归下载。
   - **📤 向服务端推送**：在推送标签页浏览本地文件，点击「🚀 推送」即可一键将单文件或整文件夹推送到服务端。

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 客户端搜索不到服务端怎么办？</b></summary>

1. 确认服务端已点击「🚀 启动服务」并且状态显示为“运行中”。
2. 确认两台电脑处于同一局域网（如连接同一路由器 WiFi 或插在同一交换机上）。
3. 若局域网路由器开启了“AP 隔离”或禁用了广播，可在客户端顶部输入框**直接手动输入服务端的 IP 地址**（例如 `192.168.1.100:8080`）点击连接。
</details>

<details>
<summary><b>Q2: 大文件传输中途拔掉网线或 WiFi 断开会怎样？</b></summary>

客户端内置了 10 次自动防抖重试机制。当网络重新恢复连接后，客户端将通过 HTTP Range 自动从断开时的字节偏移量继续传输，无需从头重新下载或上传。
</details>

<details>
<summary><b>Q3: 如何在无路由器的双机网线直连场景下使用？</b></summary>

直接使用一根网线连接两台电脑网口。Windows 会自动分配 `169.254.x.x` 的直连私有 IP。LanShare 的 UDP 发现引擎已原生适配 `169.254.255.255` 广播，两端启动后即可毫秒级自发现并高速传输。
</details>
