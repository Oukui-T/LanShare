# 局域网大文件传输系统 (LanShare V4.3)

> **当前版本**：`V4.3 (文件夹整包传输与快捷方式穿透正式版)`  
> **核心架构**：Python 3.7+ / PySide6 (Qt6) + QML (Qt Quick) + 底层系统级网络通信引擎 + 动态权限认证引擎

**LanShare V4.3** 是一套专为局域网高速、稳定传输百兆/吉字节（GB/TB 级）大文件而设计的现代化桌面端文件传输系统。具备**整文件夹一键递归下载与推送（目录结构 100% 保持）**、**Windows 快捷方式（.lnk）与符号链接真实路径自动穿透解析**、**传输状态栏多文件进度统计（已传/总数）**、**服务端共享子目录层级浏览与递归下载**、**双向严格防路径穿越安全沙箱**、服务端与客户端**权限完全隔离**、**4位动态验证码与服务端人工授权**、**连接权限验证总开关（免密开关）**、**设备复合白名单免密连接**、**UDP 毫秒级局域网自发现**、**底层强健断点续传（内置自动防抖重试）**、**耗时与动态剩余时间（ETA）预估**、**多任务排队链式调度**、**自适应 HUD 状态栏**及现代 Fluent 视觉交互界面。

## 🌟 V4.3 核心版本特性与技术亮点

1. **整文件夹一键递归下载与推送（目录结构 100% 保持，全新）**：
   * **统一操作按钮**：下载列表（Tab 1）与推送列表（Tab 2）中的文件夹统一右侧操作按钮为「📥 下载」/「🚀 推送」，双击文件夹行依然保持进入子目录。
   * **递归整包下载**：点击文件夹右侧「📥 下载」按钮，自动向服务端查询深层所有子文件并批量生成保持相对路径的下载任务；客户端本地自动多级递归建目录，下载后目录树与服务端绝对一致。
   * **递归整包推送**：点击本地文件夹右侧「🚀 推送」按钮，本地自动递归遍历所有子文件并生成相对路径，批量加入队列；服务端上传端解除截断，自动建立各级父目录并保存，目录树完全一致。
2. **Windows 快捷方式（.lnk）与符号链接真实路径穿透解析（全新）**：
   * **目录选择无缝兼容**：在服务端选择共享目录、客户端选择下载目录与推送目录时，移除了传统文件对话框的过滤限制。
   * **双保险穿透引擎**：
     * 纯 Python 基于微软官方 `[MS-SHLLINK]` 规范毫秒级二进制解析 `.lnk` 目标绝对路径（零进程开销、跨线程安全）；
     * Windows Shell 原生 COM 接口调度保底；
     * 原生 `os.path.realpath` 彻底解开 NTFS Junction 与软链接。
   * **智能目标映射**：用户点击快捷方式图标时，若指向文件夹则直接取该真实文件夹，若指向文件则自动提取其所在父目录，并校验真实有效性。
3. **传输状态栏多文件进度统计（全新）**：
   * **单文件传输**：保持极简样式，不呈现多文件计数胶囊。
   * **文件夹（多文件）传输**：在底部 HUD 状态栏精准激活多文件进度胶囊徽章：`📁 进度: 已传 X / 共 Y`（例如：`📁 进度: 3 / 12`），每个文件传输完成或跳过时，数值动态准确递增。
4. **服务端子目录层级浏览与单文件/文件夹下载**：
   * **完整层级树**：客户端「📥 从服务端下载」标签页全面支持查看服务端共享目录下的所有直属子文件夹与文件。
   * **面包屑导航**：顶部清晰呈现当前远端相对路径（如 `🌐 /`、`🌐 /docs/2026/`），并提供「⬆ 返回上级」与「🔄 刷新」按钮。
5. **坚不可摧的双重安全沙箱（防路径穿越防御）**：
   * **客户端交互受限**：远端位置严格限制在服务端共享目录树内，根目录下「⬆ 返回上级」自动物理锁死。
   * **服务端内核级校验**：服务端所有文件列表接口（`/api/files`）与数据下载/上传路由均内置 `os.path.commonpath` 严格白名单校验；一旦检测到任何越界或跨盘符请求（如 `../../` 目录逃逸），立即触发 403 Forbidden 并记录安全拦截审计日志。
6. **4位动态验证码与双向安全准入**：
   * **强制安全默认开启**：每次打开服务端窗口均默认严格启用验证码保护（会话级免密，关闭重新打开自动恢复保护）。
   * **动态轮换**：服务端生成 4 位高辨识度英数动态验证码（去混淆字符），每 2 分钟自动更新一次，支持随时手动立即刷新。
   * **便捷查看**：服务端顶部提供「🔐 验证码」按钮（图标与文字 100% 绝对正中心居中），点击弹出 Fluent 模态卡片，支持大号等宽展示、倒计时进度条与白名单管理。
   * **连接拦截**：客户端连接未授权服务端时自动弹出验证码输入窗；在通过验证前，服务端严格封锁文件目录访问（HTTP 403）。
7. **服务端权限验证总开关（免密开关）**：
   * **自由切换**：服务端验证码窗口顶部提供「启用客户端连接权限验证」Switch 开关（默认开启）。
   * **免密直连**：关闭开关后，所有局域网设备可免密直连，无需输入验证码即可直接浏览文件与传输；重新开启后恢复完整鉴权保护。
8. **服务端设备人工授权与会话级复合白名单**：
   * **弹窗授权确认**：客户端输入正确验证码后，服务端即刻弹出新设备授权确认窗口，清晰展示设备名（Hostname）与 IP 地址。
   * **`(设备名, IP)` 严格复合白名单**：确认允许后加入会话白名单；设备名或 IP 任意一个发生变动均需重新验证，兼顾便捷与安全。
   * **会话生命周期管理**：在服务端 App 运行生命周期内有效（不关界面重启服务时保持保留，重新打开 App 时自动清空）。
   * **详尽审计日志**：服务端控制台与日志视图实时记录所有验证码轮换、校验尝试、授权操作、开关切换与非法请求拦截。
9. **全新 120% 饱满双色品牌图标**：
   * 客户端与服务端统一采用 **深邃靛紫（`#451FA6`）+ 皇家蓝（`#1758DA`）** 扁平化设计。
   * 256×256 高清纯白底色，图案主体 120% 满幅填充，消除多余白边，在 Windows 任务栏与大图标模式下极其醒目。
10. **传输时间统计与动态剩余时间（ETA）预估**：
    * **已用时间**：精准记录每次传输启动时间戳，实时动态更新已用时长（如 `00:35` / `02:18`）。
    * **预估剩余时间**：基于实时传输速率与剩余字节数动态测算，呈现如 `⏱️ 剩余 01:14`。
11. **多任务排队调度与链式传输 (FIFO Queue)**：
    * **非阻塞入队**：传输进行中无需等待，点击任意文件/文件夹的「📥 下载」或「🚀 推送」即可直接加入等待队列，支持混合排队与防重复入队保护。
    * **全自动链式执行**：当前任务完成后，调度器自动取出队列头部的下一个任务并无缝启动传输。
    * **丰富队列控制**：支持「取消当前」、「全部取消」、「单项移出队列」以及「一键清空等待队列」。
12. **自适应伸缩 HUD 底部状态栏**：
    * **无任务时**：高度折叠为 0（自动隐藏，不占界面空间）。
    * **单任务传输**：高度 104px（紧凑模式，展示任务名、速率、耗时、剩余时间、进度条与操作按钮）。
    * **存在排队任务**：顶部提供 `📋 排队 (N) ▾` 按钮，展开后 HUD 平滑过渡至 230px，呈现带独立滚动条的排队抽屉清单，任务再多也不会溢出或遮挡上方文件列表。
13. **权限架构彻底隔离**：
    * **服务端**：自动通过 Windows 原生 UAC 申请管理员权限，全自动检测并放行防火墙规则（TCP 服务端口 + UDP 8088 广播端口），零需手动配网。
    * **客户端**：纯普通用户权限运行，**绝不弹出任何 UAC 权限请求**，适配公司/内网任何普通受限电脑。
14. **工业级网络稳定性与断点续传**：
    * **双向断点续传**：无论是从服务端下载还是向服务端推送，均支持 HTTP Range 协议与精准字节偏移寻道。
    * **无感断线重试**：客户端搭载底层 `curl -C -` 10 次自动重试机制，面对局域网波动、WiFi 丢包或复杂代理虚拟网卡（TUN）时自动无缝续传。

## 🚀 源码运行与使用指南

### 1. 运行服务端
```powershell
.\.venv\Scripts\python.exe server_app.py
```
- **配置共享目录与端口**：点击「📂 选择目录」指定本地共享文件夹（支持点选 Windows 快捷方式自动穿透解析）；可自定义修改端口（默认推荐 8080）。
- **查看与管理验证码**：点击顶部「🔐 验证码」，查看当前 4 位动态验证码、倒计时以及白名单列表；可在窗口内开启/关闭权限验证。
- **授权新设备**：客户端提交正确验证码后，服务端将自动弹出设备授权请求，点击「✔ 允许并加入白名单」即可建立连接。

### 2. 运行客户端
```powershell
.\.venv\Scripts\python.exe client_app.py
```
- **连接服务端**：启动后自动探测在线服务端，或在顶部输入 IP 点击「🔗 连接」。
- **权限验证输入**：若服务端启用了权限验证，将自动弹出 4 位验证码输入框，输入服务端显示的动态码后提交等待确认即可。
- **从服务端下载（单文件与整文件夹）**：
  - 点击「📥 从服务端下载」标签页，即刻浏览服务端共享目录树。
  - 双击文件夹行进入子目录；点击文件夹右侧「📥 下载」一键整包递归下载；点击文件右侧「📥 下载」下载单个文件。
- **向服务端推送（单文件与整文件夹）**：
  - 点击「📤 向服务端推送」标签页，浏览本地待推送目录。
  - 双击文件夹行进入子目录；点击文件夹右侧「🚀 推送」一键整包递归推送；点击文件右侧「🚀 推送」推送单个文件。
- **管理排队与状态**：
  - 文件夹传输时状态栏自动激活文件进度胶囊：`📁 进度: 已传 X / 共 Y`。
  - 点击「📋 排队 (N)」展开排队抽屉，可查看待传清单或点击 `✖` 移除特定任务。
